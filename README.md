# Portfolio Personnel

[https://amathie.vercel.app/](https://amathie.vercel.app/) | Hosted on Vercel

## Stack

- [Next.js](https://nextjs.org/) - Un framework react avec un rendering hybrid entre static et server-side rendering.
- [Shadcn](https://ui.shadcn.com/) - Une librairie de composants d'interface open-source.
- [Framer Motion](https://motion.dev/) - Une librairie d'animation pour react.

## Structure du projet

```
$ROOT
|
│   # App Folder
├── pages
│   # React component files
├── components
│   # Non-react modules
├── lib
│   # Static files for images
└── public
```
